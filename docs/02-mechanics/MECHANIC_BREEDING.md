# МЕХАНИКА: Бридинг (скрещивание питомцев)

> **USP-2.** Скрещивай своих питомцев, чтобы получать потомство с унаследованными признаками. Охоться за редкими генами, открывай гибридные стихии, разводи «тот самый» идеальный боец под свой стиль и торгуй генетикой на рынке.

---

## 1. ФАНТАЗИЯ ИГРОКА

Скрещивай своих питомцев, чтобы получать потомство с унаследованными признаками. Охоться за редкими генами, открывай гибридные стихии, разводи «тот самый» идеальный боец под свой стиль и торгуй генетикой на рынке.

---

## 2. ГЕНОМНАЯ МОДЕЛЬ

У каждого питомца — структурированный **геном** (живёт в Shared Core, сериализуется в сохранении):

```
struct Genome {
    visual:       VisualGenes,        // bodyShape, paletteHue, paletteSat, pattern, size, eyeStyle, aura
    stats:        StatPotentials,     // STR_pot, AGI_pot, END_pot, FOC_pot (скрытые потенциалы)
    element:      Element,            // Fire | Water | Earth | Air | Light | Dark | Arcane
    tech_affinity: TechniqueType,     // СВЯЗЬ С МЕХАНИКОЙ ЗАПИСИ УДАРОВ
    rarity:       Rarity,             // Common..Mythic — влияет на потолок и мутации
    ability:      Option<PassiveGene>,// regen, critAura, thorns…
    generation:   u32,                // растёт с каждым скрещиванием
}
```

- **MVP:** по одному значению на ген (просто и предсказуемо).
- **Фаза 2:** расширить до **аллелей (доминантный + рецессивный)** — рецессивные гены всплывают через поколение, длинная метагринда.

---

## 3. ПРАВИЛА СКРЕЩИВАНИЯ

- Два питомца стадии **Взрослый** (Lv 30+).
- Не состоят в родстве ≤3 поколений (anti-inbreeding для геймплея и разнообразия).
- Стоимость: мягкая валюта + предмет **«Love Crystal»** + кулдаун (24ч на питомца).
- Результат: **Яйцо** (инкубация в реальном времени 4–24ч; ускорение за Gems).

---

## 4. НАСЛЕДОВАНИЕ

- Для каждого гена потомок получает значение от **одного из родителей случайно (50/50)**.
- ~20+ генов → ~2²⁰ комбинаций → каждый потомок практически уникален.
- Потенциалы статов наследуются как **случайное значение в диапазоне между родителями** (с небольшим расширением границ ±5%).

```
for each gene g in child:
    parent = random_choice([parentA.g, parentB.g])      // 50/50
    child.g = parent

for each stat_potential:
    lo = min(a, b) * 0.95
    hi = max(a, b) * 1.05
    child.stat_pot = random_in_range(lo, hi)
```

---

## 5. МУТАЦИИ (главный драйвер долгой цели)

- Базовый шанс мутации одного гена: **~4%**, растёт с редкостью родителей.
- Буст: предмет **«Mutation Catalyst»** → +X%.
- **Генетическое разнообразие:** неродственные пары с разными стихиями дают **+мутации** (поощряет торговлю, а не инцест-гринд).
- Только через мутацию открываются **ультра-редкие гены**: Mythic-палитры, спецспособности, скрытые стихии.

```
mutationChance_per_gene = 0.04
    + 0.01 · avgParentRarity
    + 0.05 · (differentElement ? 1 : 0)
    + 0.10 · (mutationCatalystUsed ? 1 : 0)
    - 0.02 · inbreedingCoeff          // штраф за родство
```

---

## 6. ГИБРИДНЫЕ СТИХИИ

- Та же стихия у обоих → стабильное, предсказуемое потомство.
- Разные стихии → шанс на **гибрид**:
  - Steam = Fire + Water
  - Magma = Fire + Earth
  - Storm = Air + Water
  - и т.д. (полная таблица в `BALANCE.md`).
- Гибриды редки, мощнее в PvP, имеют уникальную графику.
- Часть комбинаций **открывается через дискавери** (collect-a-thon): игроки должны сначала найти рецептуру → сильный виральный/социальный слой.

---

## 7. ПОКОЛЕНИЯ И АНТИ-ИНФЛЯЦИЯ

- Счётчик **Generation** растёт с каждым скрещиванием.
- Лимит потенциала статов **плавно снижается после поколения N**:
```
statCapPenalty = max(0, (generation - 5)) * 0.03   // -3% за поколение после gen 5
```
- Бесконечное «выращивание сильнейшего» упирается в потолок.
- **Жёсткий потолок силы** + матчмейкинг по «эффективной силе» → bred-супер-петы попадают к равным соперникам, нет pay-to-win.

---

## 8. РОДОСЛОВНАЯ (LINEAGE)

- Дерево Lineage в companion-аппе — просмотр предков, наследственных признаков, мутаций.
- Социальный момент: «у этого питомца в роду чемпион S3».
- Рецессивные гены (фаза 2) видны в родословной как «скрытые потенциалы».

---

## 9. ИНТЕГРАЦИЯ С ЭКОНОМИКОЙ

- **Главный sink** мягкой валюты + драйвер покупок (инкубаторы, катализаторы, кристаллы).
- **Рынок (фаза 2):** продажа яиц/питомцев, «племенные услуги» (stud fees) — комиссия платформы 10%.
- Охота за редкостью = долгосрочный engagement + монетизация.

---

## 10. КЛЮЧЕВАЯ ИНТЕГРАЦИЯ С МЕХАНИКОЙ ЗАПИСИ УДАРОВ

- Ген **techAffinity** потомка даёт **бонус к определённому типу удара**.
- → Если ты записал крутые хуки, разведи питомца с аффинити «Hook» — получишь +урон/скорость именно на хуках.
- Редкий рецессивный ген **«Lineage Signature»** (ультра-редкая мутация) позволяет **наследовать коронный удар** родителя → кровь чемпионов как коллекционная ценность.

Так бридинг перестаёт быть «отдельной фичей» и становится способом **заточить питомца под твой реальный боксёрский стиль**.

```
techCardBonus = (card.type == pet.genome.tech_affinity) ? 0.15 : 0   // +15% урон/скорость
```

---

## 11. АНТИЧИТ / ЦЕЛОСТНОСТЬ

- Весь расчёт генома и мутаций — **только в Shared Core на сервере** (source of truth). Клиент лишь инициирует и видит результат.
- Seed мутации детерминирован и валидируется сервером; клиент не может «перебросить кубик».
- Логирование всех скрещиваний для расследований и rollback.

---

## 12. ПЛАТФОРМЕННАЯ РЕАЛИЗАЦИЯ

- Логика генома/мутаций — **Shared Core** (одинаково везде).
- Экран инкубатора, родословной, рынка — **companion-апп** (на часах только уведомления: «Яйцо готово!»).
- Анимация вылупления — короткая и сочная на часах (праздник игрока), расширенная версия на телефоне.

---

## 13. MVP-СКОУП

- Простая геномная модель (по 1 значению на ген, без аллелей).
- 3 базовых элемента + 1 гибрид (Steam) для демонстрации.
- Базовое наследование + базовая мутация.
- Инкубация яиц.
- Родословная в companion-аппе.

**Фаза 2:** аллели и рецессивные гены, полный набор гибридов, рынок P2P, lineage signature.
