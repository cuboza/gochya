# МЕХАНИКА: Запись ударов с акселерометра (Боевой датчик / Dojo)

> **USP-1.** Игрок записывает реальные удары в воздухе. Акселерометр + гироскоп + пульс превращают движение в **Technique Card** для PvP.

---

## 1. ФАНТАЗИЯ ИГРОКА

Твой питомец — твой ученик. Ты тренируешь его, **реально** нанося удары в воздухе. Твои настоящие движения превращаются в боевые приёмы питомца, которые он использует в PvP. Каждый питомец дерётся **в твоём личном стиле** — двух одинаковых питомцев не существует.

Дополнительно: stealth-fitness (калории, шаги, streak'и), самовыражение, глубина PvP.

---

## 2. ГЕЙМПЛЕЙНАЯ ПЕТЛЯ

1. **Dojo-режим** на часах → «Записать приём».
2. Вибрация «READY», отсчёт 3-2-1, открывается окно записи 5–8 сек.
3. Игрок выполняет удар или комбо.
4. С часов уходят **только производные метрики** (сырой сигнал не покидает устройство).
5. Сервер валидирует сессию (см. `MECHANIC_HEART_GATE.md` и `ANTICHEAT.md`) и выдаёт **Technique Card**.
6. Карта попадает в **Skill Library** → игрок собирает боевой лоадаут для PvP.

---

## 3. ЧТО ИЗМЕРЯЕМ

- **Акселерометр** (3 оси) — линейное ускорение, ~50–100 Гц.
- **Гироскоп** (3 оси) — вращение кисти/руки.
- **Пульс** — доказательство «на руке» + «боевой дух» (см. `MECHANIC_HEART_GATE.md`).

За 6 секунд = ~600 сэмплов × 6 осей ≈ 3.6K float — помещается в память и обрабатывается на устройстве.

---

## 4. КЛАССИФИКАЦИЯ ПРИЁМА (edge ML на часах)

Маленькая модель на устройстве: **TFLite Micro / ONNX Runtime / Core ML** (или DTW по шаблонам для MVP — дешевле и объяснимее).

| Параметр | Источник | Что даёт |
|---|---|---|
| **Тип удара** | классификатор (джеб, хук, апперкот, кросс, удар ногой, локоть, блок) | стихия/класс приёма |
| **Power** | пиковое |accel| в м/с² | базовый урон |
| **Speed** | время до пика | очерёдность хода в авто-битве |
| **Precision** | соответствие шаблону (form score 0–1) | модификатор урона + стабильность |
| **Combo** | число различных ударов в окне | цепочки в бою |
| **Rhythm** | дисперсия интервалов между ударами | крит, стан |

Реальные значения: пиковое ускорение удара у обычного человека ~30–80 м/с², у тренированного — 80–110+. Это даёт естественный разброс редкостей без искусственных порогов.

## 5. TECHNIQUE CARD

```
struct TechniqueCard {
    id:           Uuid,
    type:         TechniqueType,     // Jab, Hook, Uppercut, Kick, Cross, Elbow, Block
    element:      Element,           // связано с геном питомца (см. BREEDING)
    rarity:       Rarity,            // Common..Mythic (по qualityScore)
    baseDamage:   f32,               // f(power, precision, level)
    speed:        f32,               // f(executionTime) — выше = ходит раньше
    staminaCost:  u16,               // f(power)
    effect:       Option<Effect>,    // Stun/Bleed/Crit — из combo/rhythm
    signature:    bool,              // если коронный — занимает ult-слот
    ownerId:      PlayerId,          // привязка к стилю автора
    created_at:   Timestamp,
}
```

## 6. РЕДКОСТЬ ПО КАЧЕСТВУ (quality score 0–100)

| Редкость | Диапазон | Доля (ожидаемо) |
|---|---|---|
| Common | < 40 | ~55% |
| Uncommon | 40–55 | ~25% |
| Rare | 55–70 | ~13% |
| Epic | 70–85 | ~5% |
| Legendary | 85–95 | ~1.5% |
| Mythic | 95+ | ~0.5% |

---

## 7. ФОРМУЛЫ

(см. также `docs/04-core/CORE_FORMULAS.md` — единственный источник истины)

```
qualityScore   = 0.40·normPower + 0.25·precision + 0.12·comboScore + 0.08·rhythmScore + 0.15·heartScore
baseDamage     = (peakAccel / 50) · precision · typeMultiplier · techLevel
speed          = 100 / (1 + execTime_sec)
staminaCost    = round(powerRating · 2.2)
critChance     = clamp(0.02 + 0.01·comboLen + 0.05·(rhythmScore-0.5), 0, 0.35)
```

`heartScore` — из пульс-гейта (см. `MECHANIC_HEART_GATE.md`).

---

## 8. КОРОННЫЙ УДАР (SIGNATURE MOVE / ULTIMATE)

- У каждого питомца **один слот коронного приёма**.
- Лучшая запись игрока (по `qualityScore`) становится ультой — применяется по кулдауну в PvP.
- Это персонализация: **твой** питомец дерётся **твоим** лучшим ударом.

---

## 9. ПРОГРЕССИЯ И АНТИГРИНД

- **Дневной лимит записи:** 10 сессий/день (плюс премиум-слоты за Gems/GOCHYA+).
- **Мышечная память:** повторение одного типа удара слегка поднимает потолок качества (≈ +1% за 50 повторов, кап +15%).
- Достижения: «100 джебов», «Первая Mythic-карта», «Комбо из 5».

---

## 10. FITNESS-ИНТЕГРАЦИЯ

- Реальные калории и «удары» пишем в **Samsung Health / Apple Health** → игра попадает в категорию wellness, бонусная видимость.
- Weekly Challenge: «Нанеси 500 ударов за неделю» → награда.
- Training Streak — бонусы за ежедневные тренировки (retention-драйвер).
- Связь с механикой Симбиоза: пульс/кардио во время Dojo также зачисляются в дневную активность (без двойного учёта — см. `BALANCE.md`).

---

## 11. АНТИЧИТ

Серверный расчёт боя: клиент шлёт только ID выбранных карт — урон считает ядро на сервере. Подменить карту/статы нельзя.

Валидация записи (см. `MECHANIC_HEART_GATE.md` и `ANTICHEAT.md`):
- пульс-гейт (главный);
- спектральная подпись реального удара;
- гироскоп-сигнатура (вращение кисти);
- энтропия сигнала;
- rate-limit + replay-detection.

---

## 12. ПЛАТФОРМЕННАЯ РЕАЛИЗАЦИЯ

| Платформа | Sensor API | ML-модель |
|---|---|---|
| watchOS | `CMMotionManager` (`CMDeliveryLowLatency`), `HKWorkoutSession` для пульса | Core ML / TFLite |
| Wear OS | `SensorManager` (TYPE_ACCELEROMETER + TYPE_GYROSCOPE), Samsung Health Sensors API | TFLite / ONNX Runtime |
| Shared Core | принимает уже посчитанные метрики → `quality_score`, rarity, baseDamage | тот же код |

Сами формулы качества/редкости/урона — в Shared Core (одинаково везде).

## 13. MVP-СКОУП

- 5 типов ударов: Jab, Hook, Uppercut, Kick, Block.
- Простая модель классификации: DTW по 5 шаблонам (заменяется нейросетью позже).
- Дневной лимит 10 сессий.
- Signature slot.
- Skill Library (просмотр/выбор) в companion-аппе.
