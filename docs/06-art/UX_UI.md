# UX/UI ГАЙДЛАЙНЫ

> UX для двух форм-факторов (круглый Wear OS, прямоугольный watchOS) и companion на телефон. Принципы навигации, жестов, информационной архитектуры.

---

## 1. ПРИНЦИПЫ UX ДЛЯ НОСИМОГО

1. **Glanceable:** информация считывается за 1–2 секунды.
2. **Short sessions:** 30–90 секунд на часах. Никаких длинных форм.
3. **Big tap targets:** ≥ 48dp (8 мм) на часах.
4. **One screen, one action:** не смешивать заботу и магазин на одном экране.
5. **Crown/bezel first:** основная навигация — через вращение (не через тапы).
6. **Haptic feedback:** на каждом важном действии.

---

## 2. ИНФОРМАЦИОННАЯ АРХИТЕКТУРА (ЧАСЫ)

```
Главный экран (Питомец)
   │
   ├──► Уход (кормить, чистить, спать, играть)
   ├──► Тренировка (мини-игры)
   ├──► Dojo (запись удара) ★ USP
   ├──► PvP (быстрый матч, рейтинг)
   ├──► Профиль (настройки, кольца, выйти)
   │
   └── (на телефоне: Магазин, Гача, Инвентарь, Бридинг, Родословная,
                      Турниры, Лидерборд, Рынок, Друзья, BP)
```

- На часах только **быстрые действия** + питомец.
- Сложные экраны → companion-апп (через deep-link или напоминание).

## 7. COMPANION-АПП — ИНФОРМАЦИОННАЯ АРХИТЕКТУРА

Bottom Navigation (5 табов):

```
┌──────────────────────────────────────────────────────┐
│                                                       │
│                   [ активный экран ]                  │
│                                                       │
│                                                       │
├──────────────────────────────────────────────────────┤
│  🏠      🛒      ⚔️       🧬       👤               │
│ Дом    Магазин   PvP    Бридинг   Профиль            │
└──────────────────────────────────────────────────────┘
```

### 7.1. 🏠 Дом (Home)
- Питомец HD. ✅
- 4 потребности с полосами. ✅ Значения предсказываются ядром от
  `needsUpdatedAt`, чтобы питомец не стоял замороженным между чтениями профиля.
  Потребность ниже 30 получает статичную пометку «мало» и медленную пульсацию
  полосы (`ART_BIBLE.md` §5) — пульсация выключается при reduce motion, пометка
  остаётся.
- 3 кольца активности. ✅ Внутри карточки «Симбиоз» — шаги, сон и активные
  калории против серверных целей, в центре Vitality за день. Карточка заменила
  прежнюю текстовую, а не добавилась к ней: главный экран уже длинная колонка,
  и четвёртый блок стоил бы дороже, чем дают кольца.
- Бейджи дневных заданий. ❌ ещё нет.
- Quick actions. ✅

Без подключённого источника здоровья кольца остаются пустыми, а подпись зовёт
подключить его. Клиент не рисует нулевой день вместо отсутствующего —
`00-MASTER-PROMPT.md` §2.1 запрещает сочинять показатели активности.

### 7.2. 🛒 Магазин
- Tabs: Расходники | Косметика | Снаряжение | Гача | Декор | Спецпредложения.
- Карточки товаров с редкостью и ценой.
- Превью косметики на питомце (overlay).

### 7.3. ⚔️ PvP
- Tabs: Быстрый матч | Рейтинг | Турниры | История.
- Лоадаут-конструктор (drag-drop карт).
- Сезонный прогресс.
- Лидерборд.

### 7.4. 🧬 Бридинг
- Список своих питомцев с геномом-превью.
- Селектор родителей.
- Катализаторы.
- Инкубатор (яйца с прогрессом).
- Родословная (отдельный экран с деревом).

### 7.5. 👤 Профиль
- Ник и дата начала игры. ✅
- Серия заботы. ✅
- Список питомцев: стихия, стадия, уровень, поколение, отметка активного. ✅
- Настройки: выход с отзывом сессии. ⚠️ звук, уведомления и privacy ещё нет.
- Аватар, лига, рейтинг. ❌ нет эндпоинтов.
- Friends list. ❌ нет эндпоинтов.
- Battle Pass. ❌ нет эндпоинтов.
- Activity (журнал + графики). ✅ живёт отдельным экраном, вход с главной.

Всё, чего нет на сервере, **не рисуется вовсе** — ни заглушкой, ни пустой
строкой «Лига —». Пустая строка обещает то, чего бэкенд не отдаст; отсутствие
строки не обещает ничего. Тест перебирает запрещённые подписи и падает, если
любая из них появится.

## 8. ONBOARDING-ФЛОУ

```
1. Открытие (телефон) → логин через Apple/Samsung/Google
2. «Создай своего питомца» → выбрать яйцо из 3 опций (стихия)
3. Инкубация (ускорена в туториале до 5 сек)
4. Вылупление → первый питомец
5. Обучение уходу (4 потребности) на телефоне
6. «Открой на часах!» → pair
7. На часах: «Поздаравляем! Вот твой питомец»
8. Consent на HealthKit/Samsung Health
9. Кольца активности объяснение
10. Первая мини-тренировка
11. Dojo: «Запиши свой первый удар» (с пульсом)
12. Первая дуэль (vs бот)
13. Тур по магазину
14. Готово → бонус новичка

Общая длительность: 8–12 мин, с возможностью skip.
```

> ⚠️ **Аудит V8/V9 (дополнения к onboarding):**
> - **Шаг 1.5 (audit F3 — age-gate для COPPA):** после логина, перед созданием питомца — запрос даты рождения. Если < 13 лет:
>   - включить **COPPA-режим**: нет сбора health-данных, нет device fingerprint, нет аналитики;
>   - запросить **parental consent** flow (email родителя, подтверждение);
>   - закрыть доступ к IAP и PvP-рейтинговому режиму.
> - **Шаг 11 (Dojo):** критический edge-case — что если первая запись отклонена heart gate (плохой контакт)? Сделать мягкий fallback: показать «Не получилось зафиксировать пульс. Попробуй ещё раз или пропусти — карту выдадим по туториальной заготовке». **Не блокировать онбординг.**
> - **Туториальный бот (шаг 12):** loadout бота зафиксирован (3 Common-карты), AI всегда выбирает карту с минимальным уроном в первые 2 раунда, потом normal. Игрок гарантированно побеждает (positive first impression).
> - **Skip:** пропускает обучение, но НЕ пропускает обязательные шаги (1, 2, 3 — аккаунт/consent/age-gate). Остальное можно skip'нуть.

### Empty / Error / Loading states (audit V8 — добавить ко всем экранам)

Для каждого экрана companion и watch-клиента должны быть определены:
- **Loading:** skeleton/spinner с фирменным стилем (питомец «думает», а не голый спиннер).
  ✅ Companion: `GochyaLoader` — четыре точки в палитре потребностей (голод,
  энергия, гигиена, настроение) волной, плюс конкретная подпись: «Ищем
  соперника…», «Считаем Vitality…», а не «Загрузка». Силуэт существа был бы
  ближе к букве требования, но весь арт — постихийный, а экран до загрузки не
  знает вида питомца; выбрать один значило бы пообещать существо, которого у
  игрока может не быть. При reduce motion точки замирают, но остаются на месте.
  Спиннеры внутри кнопок оставлены как есть — требование про экраны.
- **Empty:** когда нет данных (нет питомцев, нет боёв, нет друзей) — иконка + CTA («Создай первого питомца», «Добавь друга»).
- **Error:** дружелюбное сообщение + кнопка retry. Для сетевых ошибок — оффлайн-баннер «Не получилось сохранить. Покажем, когда появится связь».
- **No-permission:** для Health/Sensors — «Доступ запрещён. Открой настройки».

## 9. УВЕДОМЛЕНИЯ — ПОЛНЫЙ КАТАЛОГ (audit V8)

- **Заголовок:** ≤ 30 символов.
- **Текст:** ≤ 60 символов.
- **Action:** тап → переход на конкретный экран (deep link).
- **Частота:** ≤ 3/день, priority queue.
- **Тихие часы:** 22:00–07:00 по timezone игрока (кроме срочных).
- **Cooldown per template:** 1 push/шаблон в день (кроме priority 1).

| `pet.dirty` | 3 | hygiene=0 >6h | `{petName} needs a bath` | `Things got messy...` | `/pet/clean` | 1/2дня |
| `egg.ready` | 1 | incubation done | `Egg is ready!` | `Tap to hatch 🥚` | `/breeding/incubator` | нет |

### Ключи локализации
- Формат: `notifications.{template_id}.title` / `.body`.
- Плюрали (русский): использовать ICU MessageFormat (`{steps, plural, one {# шаг} few {# шага} many {# шагов}}`).

## 10. ДОСТУПНОСТЬ

- **Dynamic Type** (iOS) / **Font scale** (Android) — поддержка.
- **VoiceOver / TalkBack** — основные экраны с описаниями.
- **Color contrast** — WCAG AA минимум.
- **Reduce Motion** — упрощённые анимации.
- **Haptics** — опционально, не единственный канал.

## 11. ТЕМЫ

- **Dark** ✅ (по умолчанию, экономит батарею на OLED).
- **Light** ❌ спека есть, реализации нет. Палитра посчитана и проверена в
  `ART_BIBLE.md` §3.5; токены тёмной темы переиспользовать **нельзя** —
  11 из 14 не проходят даже 3:1 на светлой подложке.

- Сезонные темы (зима, Хэллоуин) — как seasonal content, ❌ фаза 3
  (`ART_BIBLE.md` §11).
