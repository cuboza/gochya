# АРТ-БИБЛИЯ GOCHYA

> Визуальный стиль проекта для всех платформ (watchOS, Wear OS, companion). Цель — премиальный soft-3D/2.5D, не ретро.

---

## 1. ВИЗУАЛЬНАЯ ФИЛОСОФИЯ

**GOCHYA выглядит современно и дорого.** Никакого пиксель-арта, никакой 8-битной ностальгии. Чистый, сочный, мягкий стиль — как у лучших мобильных игр (Genshin Impact, Sky: Children of the Light, Monster Hunter Stories), адаптированный под маленький круглый экран.

**Три слова-определения:** `Soft · Vibrant · Alive`

- **Soft** — мягкие формы, скругления, нет агрессивных углов.
- **Vibrant** — сочные, насыщенные цвета, но не кричащие.
- **Alive** — постоянное микро-движение, дыхание, реакция.

---

## 2. СТИЛЬ СУЩЕСТВА

### 2.1. Подход: Soft 3D (low-poly с PBR-шейдингом)
- Низкополигональные модели с гладким шейдингом (не faceted).
- Тёплое освещение, мягкие тени.
- Сочковые материалы: как у качественной виниловой игрушки (Art Toy / Designer Toy).
- Параллакс-фон для глубины.

**Альтернатива (MVP, если 3D выходит дорого):** высококачественный 2D-skeletal (Spine/Rive) с параллаксом и «псевдо-3D» глубиной.

### 2.2. Анатомия существа
- Крупная голова, большие выразительные глаза.
- Маленькое тело, короткие лапки — пропорции «baby schema» (миловидность).
- Подвижные уши/хвост/крылья (зависит от вида).
- Эмоции через мимику: глаза, брови, рот, поза.

### 2.3. Эмоции (минимум 12 стейт-анимаций)
| Состояние | Анимация | Когда |
|---|---|---|
| Idle (happy) | лёгкое покачивание, моргание | по умолчанию |
| Excited | подпрыгивает, частицы | успех, награда |
| Sad | уши опущены, слёзы | mood низкий |
| Hungry | смотрит на еду, урчит | hunger низкий |
| Sleepy | зевает, глаза закрываются | energy низкий |
| Sleeping | спит, Z-частицы | ночь |
| Dirty | грязные пятна, чесется | hygiene низкий |
| Angry | хмурится, фыркает | before PvP |
| Battle pose | боевая стойка | в бою |
| Hurt | вздрагивает, искры | получил урон |
| Love | сердечки, обнимашки | обнимаем |
| Evolve | сияние, трансформация | эволюция |

### 2.4. Эффекты (particles)
- ❤️ сердечки — любовь, mood up.
- ✨ искры — успех, лут.
- 🌟 звёздочки — эволюция, Mythic.
- 💧 капли — купание.
- 🍴 крошки — еда.
- 💤 Z — сон.
- 🔥 элементные частицы — Fire/Steam/Magma и т.д.

## 6. UI-KIT

### 6.1. Кнопки
- Скругление 16px (на часах — относительное, ~20% высоты).
- Минимальный tap-target: **44×44 pt** (Apple HIG), на часах — 48×48dp (8 мм).
- Состояния: normal, pressed, disabled, loading.

### 6.2. Карточки
- Скругление 20px.
- Тонкая тень (elevation 2).
- На часах — занимают 90% ширины с безопасными отступами.

### 6.3. Индикаторы прогресса
- Кольца (как Apple Activity) для колец активности.
- Линейные полосы — для XP/HP.
- Дуги вокруг существа — для потребностей.

## 7. БЕЗОПАСНЫЕ ЗОНЫ (круглый экран Wear OS)

```
        ╭─────────────────────╮
       ╱  ⚠ clip zone          ╲   ← края обрезаются, контент не тут
      ╱                         ╲
     │   ┌─────────────────┐     │
     │   │                 │     │   ← безопасная зона (~85% площади)
     │   │     CONTENT     │     │
     │   │                 │     │
     │   └─────────────────┘     │
      ╲                         ╱
       ╲                       ╱
        ╰─────────────────────╯
```

- Все тап-таргеты и текст — внутри круга.
- Частицы могут выходить за края (красиво).
- Использовать `BoxInsetLayout` (Wear OS) / safe-area insets (watchOS).

## 8. AOD (Always-On Display)

- **Монохром** или один акцентный цвет.
- Питомец — стилизованная силуэтная пиктограмма.
- 1 FPS.
- Минимум элементов: существо + 1 индикатор (напр. mood или Vitality-кольцо).
- Внизу — время.

```
   ┌───────────┐
   │           │
   │   ◗_◖     │   ← силуэт существа, спит/бодр
   │           │
   │  ◐ Vitality│
   │  14:32    │
   └───────────┘
```

## 9. АНИМАЦИИ

### 9.1. Принципы (Disney 12 + mobile)
- Squash & stretch, anticipation, follow-through.
- Easing: не linear, предпочтение `easeOutBack` для UI, `easeInOutQuad` для переходов.
- Длительность: tap feedback 150ms, screen transition 300ms.

### 9.2. События-анимации
| Событие | Анимация | Длительность |
|---|---|---|
| Покормить | еда летит в рот, частицы | 600ms |
| Чистить | пена, капли, сияние | 1.5s (mini-game) |
| Обнять | сердце лопается, mood up | 800ms |
| Получить карту | карта вылетает, переворот, редкость-свечение | 1.2s |
| Эволюция | сияние, рост, форма меняется | 2s (праздничная) |
| Боевой раунд | удар, искры, HP-бар | 400ms/раунд |
| Победа | конфетти, питомец радуется | 1.5s |
| Поражение | питомец грустит, тёмная вуаль | 1.5s |

## 10. АРТ-ПАЙПЛАЙН ПОД 3 РАНТАЙМА

| Этап | Инструмент | Выход |
|---|---|---|
| Концепт | Procreate / Photoshop | арт-дирекшн |
| 3D-модель | Blender | `.blend`, low-poly + bake |
| 3D → watchOS | Blender → SceneKit `.scn` | `.scn` файл |
| 3D → Unity (Wear OS) | Blender → FBX/glTF → Unity prefab | `.prefab` + ASTC textures |
| 3D → companion (Flutter) | рендер в спрайт-атлас ИЛИ Rive для UI | png/webp |
| 2D-skeletal (fallback) | Spine / Rive | `.json` + atlas |
| UI-анимации | Lottie / Rive | `.json` / `.riv` |
| Иконки | Figma / Illustrator | SVG → PNG @1x/2x/3x |

**Принцип:** модель авторится ОДИН РАЗ, экспорт под каждый рантайм.

## 11. ТЕМИЗАЦИЯ

### 11.1. Время суток
- **Утро:** тёплый рассветный свет, лёгкий туман, птички.
- **День:** яркое небо, активные частицы.
- **Вечер:** оранжевый закат, длинные тени.
- **Ночь:** синяя палитра, звёзды, питомец спит.

### 11.2. Сезоны
- Зима: снег, новогодние декоры.
- Весна: цветение, лепестки.
- Лето: яркое солнце, бабочки.
- Осень: листья, тёплые тона.

### 11.3. Праздники
- Хэллоуин: тыквы, призраки, оранжево-фиолетовая тема.
- Новый год: салюты, подарки.

## 12. ЗВУК (минимальный)

- **На часах:** только короткие SFX (тап, успех, ошибка). Музыка — выкл по умолчанию (батарея +ux).
- **На телефоне:** фоновая музыка (3–5 треков, ambient), SFX на действия, победа/поражение.
- Все звуки — отключаемые в настройках.
