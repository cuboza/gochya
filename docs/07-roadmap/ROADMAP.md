# ROADMAP — дорожная карта GOCHYA

> От pre-production до глобального релиза + оперплан на 12 месяцев после launch.

---

## 1. ОБЩИЙ ВИД

```
Pre-Prod (4 нед) → MVP (16 нед) → Alpha (6 нед) → Beta (8 нед) → Soft Launch (8 нед) → Global Launch
                                       ↑                ↑               ↑
                                  внутреннее       закрытый тест     1 регион
                                  тестирование     (1000–5000 чел)   ( Philippines / CA )
```

**Итого до Global Launch:** ~42 недели (~10 месяцев). MVP требует примерно 8–11 FTE; Alpha/Beta уточняются после Sprint 0 и MVP.

---

## 2. ФАЗЫ

### 2.1. Pre-production (4 недели)
**Цель:** архитектурный фундамент, спайки, концепт.

| Неделя | Деливерабл |
|---|---|
| 1 | Документация финализирована (✅ эта). Структура монорепо. |
| 2 | Shared Core: базовые типы, hello-formula (quality_score), FFI-spikes под iOS+Android. |
| 3 | Backend scaffolding: auth, profile, БД-схема. Art-концепты существа. |
| 4 | Vertical spike: «запиши удар → получи карту» end-to-end на одной платформе. |

**Gate:** FFI работает, формулы одинаковый результат на всех таргетах.

### 2.2. MVP Production (16 недель)
См. `MVP.md`. К концу — вертикальный срез играбелен на телефоне и Wear OS. Для watchOS в MVP обязателен только Gate 2 spike; полноценный клиент входит в Beta.

### 2.3. Alpha (6 недель)
**Цель:** внутреннее тестирование, баланс.

- Ranked PvP, ELO и лиги.
- Друзья, социальный спарринг и лидерборды.
- Gems, IAP, один гача-баннер и store validation.
- Отдельные мини-игры Agility/Endurance/Focus.
- Ежедневные playtest'ы команды.
- Баланс формул (урон, экономика, гача).
- Исправление крэш-багов, перф-оптимизация.
- Нагрузочное тестирование бэкенда (10 000 коннектов).
- Настройка observability.

**Gate:** Crash-free ≥ 99.5%, perf в бюджете, нет критических багов.

### 2.4. Beta (8 недель)
**Цель:** закрытый тест с реальными пользователями (1000–5000).

- Полноценный watchOS-клиент.
- Сезонный чемпионат, Crowns и Battle Pass.
- TestFlight (iOS) + Google Play Console internal + Galaxy Store beta.
- Сбор метрик: retention, конверсия, churn-причины.
- A/B-тесты: онбординг, баланс экономики, частота пушей.
- Локализация (EN/RU в MVP).
- Финальная юридическая проверка (privacy, COPPA, ToS).

**Gate (для Soft Launch):**
- D1 retention ≥ 35%
- D7 retention ≥ 12%
- Crash-free ≥ 99.5%
- Нет severity-1 багов.

### 2.5. Soft Launch (8 недель)
**Цель:** проверка метрик на одном регионе (Канада или Филиппины).

- Публичный релиз в одном регионе.
- KPI-мониторинг: DAU, retention, ARPDAU, конверсия в платящего.
- LiveOps: первый сезон, A/B на баланс/монетизацию.
- Capacity-тест: реальные пиковые нагрузки.

**Gate (для Global):**
- D1 retention ≥ 40%
- D7 retention ≥ 15%
- Конверсия в платящего ≥ 2%
- ARPDAU ≥ $0.05
- Crash-free ≥ 99.7%

### 2.6. Global Launch
- Релиз во всех регионах.
- Маркетинговая кампания (Samsung-партнёрство — приоритет).
- LiveOps-команда 24/7 в первую неделю.
- Активный мониторинг метрик, hotfixes.

## 3. POST-LAUNCH — ОПЕРАЦИОННЫЙ ПЛАН (12 МЕСЯЦЕВ)

### Годовой контент-план (сезоны по 4 недели = 13 сезонов)

| Квартал | Фокус | Главные фичи |
|---|---|---|
| **Q1** | Удержание + PvP-мета | Сезоны 1–3, первый новый вид существа, расширение гачи, кланы (фаза 2) |
| **Q2** | Бридинг-мета | Рецессивные гены, полный набор гибридов, рынок P2P, расширенные турниры |
| **Q3** | Симбиоз-углубление | Стресс-метрика, все типы тренировок, социальная синергия, эволюционные ветви от активности |
| **Q4** | Масштабирование | Подписка GOCHYA+, сезонные ивенты (Хэллоуин/Новый год), новые локализации (CN/JP/KR), коллаборации |

### Каденция релизов
- **Каждые 2 недели:** minor-патч (баланс, баги, мелкие фичи).
- **Каждые 4 недели:** новый сезон (контент, ивент, Battle Pass).
- **Каждые 12 недель:** крупное обновление (новая механика/платформа).

### LiveOps-команда (post-launch)
- LiveOps Producer
- Game Designer (баланс/ивенты)
- Community Manager
- Data Analyst
- QA ongoing
- Часть core-команды на new features
