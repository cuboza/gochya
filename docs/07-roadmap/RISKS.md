## 2. ДЕТАЛИЗАЦИЯ ТOP-5 РИСКОВ

### R1. Батарея/перформанс на 2 рантаймах ⚠️
**Проблема:** Unity и SwiftUI по-разному работают с GPU/CPU; маленький экран и ограниченная батарея.

**Митигация:**
- Performance-бюджет определён с дня 1 (`CLIENT_*.md`).
- Тестирование на реальных устройствах (Galaxy Watch 6/7, Apple Watch S9/Ultra) каждую неделю.
- AOD: 1 FPS, монохром, минимум элементов.
- Dojo: сенсоры включены только на 16 секунд.
- Background: нулевой поллинг игрой, только системные health-aggregates.
- Профилирование: Xcode Instruments, Android Studio Profiler, Unity Profiler.

**Trigger эскалации:** расход батареи в фоне > 3%/час → stop-the-line до исправления.

### R2. Античит в PvP и записи ударов ⚠️
**Проблема:** игроки подделывают удары, win-trade, эксплойтят экономику.

**Митигация:**
- Server-authority для всех исходов (бой, IAP, геном, мутации).
- Heart gate как главный шлюз записи удара (см. `MECHANIC_HEART_GATE.md`).
- Многослойная валидация: спектр + гироскоп + энтропия + replay + rate-limit (см. `ANTICHEAT.md`).
- Double-entry ledger для экономики с consistency check.
- Логирование всех подозрительных событий → ревью.

**Trigger:** > 1% SUSPECT-записей → добавить новые эвристики.

### R3. Двойная клиентская разработка ⚠️
**Проблема:** Unity + SwiftUI = 2 команды, 2 набора багов, риск расхождения.

**Митигация:**
- **Максимум логики в Shared Core** — UI-оболочки тонкие.
- Паритет-контракт: обе платформы поддерживают один и тот же набор фич.
- Cross-platform golden tests: поведение ядра идентично.
- Приоритет: Wear OS (Unity) первая до MVP, watchOS — на Beta.

**Trigger:** расхождение в паритет-фичах > 2 недель → перераспределить ресурсы.

### R4. Ретеншн после новизны ⚠️
**Проблема:** классический тамагочи-эффект — бросают через 2 недели.

**Митигация:**
- **Бридинг** как долгая цель (3–8 недель на поколение, бесконечная мета).
- **Симбиоз** формирует привычку (возвращаешься «отметиться» активностью).
- **Сезоны** каждые 4 недели — новый контент, BP, ивент.
- **Социальные** лиги/турниры — стимул не выпадать.
- LiveOps-команда с оперпланом на 12 месяцев.

**Gate (Soft Launch):** D7 ≥ 15%. Если ниже → пересмотреть контент-план, добавить long-term goal.

### R5. Compliance (COPPA/GDPR-K) ⚠️
**Проблема:** возможная детская аудитория → жёсткие правила сбора данных.

**Митигация:**
- Юридический ревью на pre-production.
- Age-gate при регистрации (если <13 — COPPA-режим без сбора health-данных).
- Parental consent flow для детей.
- Прозрачная политика конфиденциальности.
- GDPR: экспорт/удаление данных по запросу.
- App Store Kids Category — опционально, если решим позиционироваться для детей.

## 4. ДЕГРАДИРОВАННЫЕ РЕЖИМЫ (graceful degradation)

Когда что-то идёт не так, игра должна деградировать мягко:

| Ситуация | Поведение |
|---|---|
| Нет сети | Офлайн-уход (кормить/чистить/тренировать), sync при reconnect |
| Нет Health-доступа | Базовый режим (~60% прогресса), без штрафов |
| Нет пульс-сенсора | Dojo недоступен, остальной геймплей работает |
| Сервер даун (бой) | Дружественное сообщение, не блокирует часы |
| Слабое устройство | Снижение FPS до 30, упрощённые шейдеры, меньше частиц |
| Плохой контакт часов | Soft-retry в Dojo, не блокировка |
